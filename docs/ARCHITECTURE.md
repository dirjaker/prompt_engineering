## 二、核心模块

### 2.1 数据模型层 (`models.py`)

使用 Pydantic v2 定义所有数据模型，提供类型安全和自动验证。

**枚举类型：**

| 枚举 | 值 | 说明 |
|------|------|------|
| `VariableType` | string, integer, float, boolean, list, dict | 变量类型 |
| `PromptStatus` | draft, active, archived | Prompt 状态 |
| `EvalMetric` | accuracy, relevance, format, fluency, completeness | 评估维度 |
| `ABTestStatus` | draft, running, completed, cancelled | A/B 测试状态 |

**核心模型：**

| 模型 | 说明 |
|------|------|
| `VariableDefinition` | 变量定义（名称、类型、默认值、枚举约束） |
| `PromptVersion` | Prompt 版本（模板、变量、系统提示、模型参数） |
| `Prompt` | Prompt 主体（名称、分类、标签、状态、版本列表） |
| `EvalResult` | 评估结果（指标、分数、输入/输出样本） |
| `ABTest` / `ABTestVariant` | A/B 测试配置与变体 |
| `RenderRequest` / `EvalRequest` | API 请求模型 |

### 2.2 模板引擎 (`template_engine.py`)

基于 Jinja2 沙箱环境的模板引擎，核心特性：

- **安全渲染**：使用 `SandboxedEnvironment` 防止模板注入攻击
- **严格未定义检测**：自定义 `_StrictUndefined`，访问未定义变量立即报错
- **变量验证**：自动提取模板变量，验证类型和必填性
- **内置过滤器**：`upper`, `lower`, `title`, `truncate`, `to_json`, `join`, `default`, `word_count`, `strip`

**模板语法示例：**

```jinja2
你是{{ role | default("助手") }}，请{{ action }}以下内容：

{{ content }}

输出语言：{{ language | upper }}
```

### 2.3 数据库层 (`database.py`)

SQLite 数据库封装，核心设计：

- **WAL 模式**：`PRAGMA journal_mode=WAL`，提升并发读写性能
- **自动建表**：首次连接自动创建 `prompts`、`prompt_versions`、`eval_results`、`ab_tests` 四张表
- **索引优化**：对 `prompt_id`、`category`、`status` 建立索引
- **级联删除**：删除 Prompt 时同步清理关联的版本和评估结果

**数据表结构：**

```sql
prompts           -- Prompt 主表
prompt_versions   -- 版本历史（外键关联 prompts）
eval_results      -- 评估结果（外键关联 prompts）
ab_tests          -- A/B 测试（独立表）
```

### 2.4 评估引擎 (`evaluator.py`)

五维自动评估引擎，当前使用模拟模式：

| 维度 | 评分逻辑 |
|------|----------|
| `accuracy` | 基于输出长度 + prompt 长度的启发式评分 |
| `relevance` | 基于 prompt 与输出的词汇重叠度 |
| `format` | 检测代码块标记和换行符 |
| `fluency` | 基于句子数量的流畅度评分 |
| `completeness` | 基于输出长度的完整性评分 |

**A/B 测试流程：**

1. 接收变体列表（至少 2 个）和样本量
2. 对每个变体执行 N 次模拟评估
3. 统计每个变体的均值、标准差、极值
4. 评选最优变体（均值最高者）

### 2.5 API 服务 (`api.py`)

FastAPI 应用，通过 `lifespan` 管理资源生命周期。共 17 个 API 端点：

- Prompt CRUD：4 个端点
- 版本管理：3 个端点
- 渲染与评估：3 个端点
- A/B 测试：4 个端点
- 模板工具：2 个端点
- 统计：1 个端点

## 三、技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| Web 框架 | FastAPI | 异步支持、自动 OpenAPI 文档、Pydantic 集成 |
| 数据验证 | Pydantic v2 | 性能优秀、类型安全、JSON Schema 自动生成 |
| 模板引擎 | Jinja2 沙箱 | 安全、灵活、Python 生态标准 |
| 数据库 | SQLite | 零配置、单文件部署、WAL 模式支持并发 |
| 服务器 | Uvicorn | 高性能 ASGI 服务器 |

## 四、配置说明

配置文件 `config.yaml` 包含以下配置段：

| 配置段 | 说明 |
|--------|------|
| `app` | 应用名称、版本、监听地址、端口、调试模式 |
| `database` | 数据库文件路径 |
| `template` | 模板最大长度、最大变量数、严格模式 |
| `evaluation` | 默认评估指标、模拟模式、样本量限制 |
| `defaults` | 默认模型、温度、最大 token 数 |
| `categories` | 预定义分类列表 |
